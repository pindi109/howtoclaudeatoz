# Claude for On-Page SEO Optimisation — Full Guide (2026)

*Last updated: 2026-06-07*

Using Claude for on-page SEO means applying AI reasoning to the elements of a page that directly influence search rankings: content depth, keyword placement, heading structure, meta tags, internal links, and readability. Claude for on-page SEO is not a replacement for scoring tools like Surfer SEO — it is the implementation layer. Surfer tells you what score to hit and what topics to cover; Claude writes the content that gets you there. This guide walks through every on-page element Claude can optimise, the prompts that produce the best output, and how to combine Claude with Surfer SEO for a data-driven workflow.

## What is On-Page SEO — and How Does Claude Help?

On-page SEO refers to every element on a web page that you can control to influence its search engine rankings. This includes the content itself, how it is structured, the keywords it contains, the metadata, and how it links to other pages on your site.

Claude's contribution to on-page SEO sits in three areas:

1. **Content quality** — ensuring the page covers a topic thoroughly, answers the right questions, and reads naturally for human visitors
2. **Structural optimisation** — improving heading hierarchy, keyword placement, and content organisation
3. **Completeness analysis** — identifying topics or sections that competitors cover but your page is missing

What Claude cannot do is score your page against a live SERP or measure technical performance factors like load speed. For those, Surfer SEO or Google Search Console is necessary.

## How to Optimise a Page with Claude — Step by Step

### Step 1: Audit the existing page

Paste your page content into Claude and request an initial assessment:

```
You are an expert SEO copywriter. Analyse this page content for on-page SEO quality.

Target keyword: [primary keyword]
URL: [page URL]
Current ranking position: [position if known]

Page content:
[paste full page text]

Assess:
1. Is the primary keyword in the first 100 words?
2. Does the H1 include the primary keyword?
3. Do the H2s cover the main sub-topics a searcher would expect?
4. Is the content comprehensive or does it miss important angles?
5. Are there any keyword stuffing issues?
6. What are the top 5 improvements that would have the most impact on rankings?
```

### Step 2: Rewrite the introduction

The opening paragraph is the most important section for both users and search engines. Ask Claude to rewrite it with precision:

```
Rewrite the introduction of this page so that:
1. The primary keyword "[keyword]" appears naturally within the first 2 sentences
2. The paragraph directly answers the main search query — no vague warm-up sentences
3. The length is 80-120 words
4. The tone is [professional / conversational / authoritative]

Original introduction:
[paste current intro]
```

### Step 3: Improve heading structure

A well-structured heading hierarchy helps Google understand the page and helps users navigate. Use this prompt:

```
Suggest an improved H2 and H3 structure for this page targeting the keyword "[keyword]".

Current heading structure:
[paste current headings]

Requirements:
- H1 should contain the primary keyword
- H2s should cover the main user questions and sub-topics
- Include at least one H2 that addresses "what is" or "how to"
- Use secondary keywords naturally in 2-3 of the H2s
- Avoid repetitive heading phrases

Secondary keywords to include: [list]
```

### Step 4: Add missing content sections

Compare your page to what top-ranking competitors cover. If you have Surfer SEO, paste the missing topic suggestions from the Content Editor. If not, ask Claude to analyse from first principles:

```
Based on the keyword "[keyword]" and what a searcher typing this would expect to find, what major topics or sections does this page currently NOT cover?

Current page headings: [list your H2s]

List the 5-8 most important missing sections, with a brief description of what each should include.
```

### Step 5: Optimise keyword placement throughout the body

After structural improvements, review keyword usage:

```
Review this page content for keyword optimisation. The primary keyword is "[keyword]". Secondary keywords are: [list].

Check:
1. Does the primary keyword appear 3-5 times naturally (no stuffing)?
2. Are secondary keywords used at least once each?
3. Are there any awkward or forced keyword placements that need fixing?
4. Are there long sections (300+ words) with no keyword mention?

Suggest specific edits — show the current sentence and your improved version.
```

### Step 6: Write FAQ and summary sections

FAQ sections improve chances of appearing in People Also Ask results. Summaries improve featured snippet potential:

```
Write a 5-question FAQ section for this page about "[topic]". 

Requirements:
- Questions should match how real users phrase searches (check People Also Ask for "[keyword]" for inspiration)
- Each answer should be 40-80 words — long enough to be useful, short enough for a snippet
- Answers should be self-contained — readable without the question context
- Include the primary keyword in at least 2 answers naturally

Also write a 3-sentence page summary suitable for a "Key Takeaways" box at the end of the article.
```

### Step 7: Internal link suggestions

Ask Claude to identify internal linking opportunities based on your existing content:

```
Here are the other pages on my site: [paste list of page titles and URLs]

Based on this page's topic ("[topic]"), which of my existing pages would be most relevant to link to? 

For each suggested link:
- Quote the section of this page where the link should sit
- Suggest the anchor text
- Explain the relevance
```

## Claude On-Page SEO Workflow — Full Page Optimisation

For a complete page optimisation, work through these tasks in order:

1. Initial audit (Step 1) — understand what needs to change
2. Meta title and description — rewrite first, as these frame everything else
3. H1 rewrite — align with the meta title and primary keyword
4. Introduction rewrite — ensure keyword in first 100 words
5. Heading structure review — add missing sections, improve H2 keyword coverage
6. Body content additions — fill topic gaps identified in audit
7. FAQ section — add or improve for snippet and PAA opportunities
8. Internal links — add 3-5 relevant links per page
9. Image alt text — write descriptive alt text for any images

A complete optimisation run on a single page takes 30-45 minutes using Claude and produces improvements that typically move a page from position 8-15 into the top 5 within 60-90 days, depending on competition and domain authority.

| Missing topic identification | Good | Excellent with data |
| Heading optimisation | Excellent | Moderate |
| Readability improvement | Excellent | No |
| FAQ and summary writing | Excellent | No |
| Competitor content comparison | Good | Excellent with data |
| Price | From $20/mo | From $89/mo |

Use Surfer SEO for the data targets (word count, NLP score, topics to cover), then use Claude to implement all the actual content changes. The combination produces better results than either tool alone.
